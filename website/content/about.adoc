WarmDesk is a self-hosted project management tool built for software teams that want to own their own data.
It covers Kanban boards, Scrum sprints, team chat (including one-to-one voice/video and group video calls), customer management, time tracking, and Git integration — all in a single statically-linked Go binary.

== The experiment

This project started as an experiment: _can a fully-featured application be built almost entirely with AI assistance?_

Almost every line of code was generated by https://claude.ai/code[Claude Code] and https://cursor.sh[Cursor], guided by a detailed `what.md` specification file.
The result is a ~45,000 line Go backend and a ~45,000 line Vue 3 frontend that actually works.

== Technology

[cols="1,2", options="header"]
|===
|Layer |Technology

|Backend
|Go 1.26, Gin, GORM, SQLite / PostgreSQL / MySQL

|Frontend
|Vue 3.5, Vite 8, Pinia 3, Vue Router 5, vue-i18n 11

|Desktop
|Tauri 2.11 · Rust 1.94 (Linux, macOS, Windows)

|Real-time
|WebSocket hub (optional Redis pub/sub for multi-instance)

|Auth
|JWT HS256, TOTP/MFA, bcrypt (cost 12), API keys

|i18n
|12 languages (en, nl, de, fr, es, da, sv, nb, fi, is, pt, it)
|===
